# 🐾 JeevRaksha — Animal Disease Finder

> A multilingual, user-friendly web application for identifying common animal diseases from symptoms and providing basic care and prevention guidance.

## 🌟 Overview

**JeevRaksha (जीवरक्षा)** is a frontend-based animal health assistance project created to make basic animal disease information easier to access. Users can select an animal, enter or select symptoms, and view possible disease information, symptoms, prevention tips, and general care guidance.

The project is designed as an educational and awareness tool. It is **not a replacement for a qualified veterinarian or professional veterinary diagnosis**.

## ✨ Key Features

- 🔎 Symptom-based animal disease finder
- 🐾 Support for multiple domestic and farm animals
- 🌐 Multilingual interface with English, Hindi, and Marathi support
- 📱 Responsive design for desktop and mobile screens
- 💡 Disease information with symptoms and prevention guidance
- 🎨 Clean and accessible user interface
- ⚡ Lightweight frontend implementation
- 🧩 Easily expandable animal and disease database

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Ganeshawale97/Animal-Disease-Finder.git
```

### 2. Open the project

Open the repository folder in VS Code or another code editor.

### 3. Run the application

Open the selected HTML file in a browser, or use the **Live Server** extension in VS Code for a better development experience.
