# Contributing to JeevRaksha

Thank you for your interest in improving JeevRaksha! Contributions that improve usability, accessibility, documentation, code quality, and educational value are welcome.

## Getting Started

1. Fork the repository.
2. Clone your fork locally.
3. Create a feature branch.
4. Make your changes.
5. Test the application in a modern browser.
6. Commit your changes with a clear message.
7. Open a pull request describing what changed and why.

## Contribution Ideas

- Add validated animal/disease information.
- Improve translations.
- Improve responsive layouts.
- Fix accessibility issues.
- Improve symptom matching logic.
- Add automated tests.
- Improve documentation.

## Content Guidelines

Disease and treatment-related content should be reviewed against reliable veterinary sources before being added. Do not present the application as a substitute for professional veterinary diagnosis or treatment.

## Code Guidelines

- Keep HTML semantic and readable.
- Prefer reusable CSS classes.
- Keep JavaScript modular and understandable.
- Avoid hard-coded secrets or private data.
- Test changes on desktop and mobile layouts.

## Pull Requests

Please include:

- A short summary of the change.
- Screenshots for visual changes where useful.
- Testing performed.
- Any known limitations.

## Code of Conduct

Be respectful, constructive, and inclusive when communicating with contributors and maintainers.
